# Лабораторная работа №1

Приложение «Идеальное похудение» для варианта 17. Java Swing, MVC с активной моделью.

## Запуск

```bash
javac -d out src/*.java
java -cp out Main
```

Программа рассчитывает начальный и целевой пульс по формуле Карвонена. Для расчёта используются интенсивности 50% и 70% резерва пульса.
