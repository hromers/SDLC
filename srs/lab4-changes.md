# Проект изменений SRS для ЛР4

Версия 0.2 · 19.11.2026. Дополнение к [базовой SRS 0.1](srs-template.md). Основные FR-001–FR-008 и NFR-001–NFR-007 остаются базовой линией существующего кода. Ниже — статусы в учебном сценарии, не подтверждение внешнего согласования.

## FR-009 Встроенная справка

Источник: BR-002, уменьшение ошибок понимания. Приоритет 50 Optional; статус Deferred после раунда 1. В отдельном окне предполагались формула, обозначения и пример A=30, R=60 → 125 и 151. F09 = 3 дня; следующий релиз вне итогового плана. Постоянная учебная подпись NFR-007 остается обязательной. Кода справки нет.

## FR-010 Копирование принятого результата

Источник: BR-003, повторное использование результата без ручного переписывания. Приоритет 30 Medium; статус Proposed после раунда 2. По явной кнопке система должна копировать текст последнего успешного расчета: возраст, пульс покоя, тренажер, начальный и целевой пульс с уд/мин, учебное назначение.

До первого успешного расчета кнопка недоступна. После ошибки или отмены копируется последний принятый результат. После успешного повторного расчета текст соответствует новым данным, включая тренажер. При занятом или недоступном буфере показывается причина; состояние модели и результат не меняются. Для A=30, R=60 текст содержит 125 и 151 уд/мин. Наличие функции не заявляется: это проект следующего релиза, F10 = 2 дня.

## Проект уточнения NFR-002

Базовое NFR-002 запрещает передачу параметров за пределы памяти приложения. Для совместимости с FR-010 предложено: «Приложение не отправляет параметры по сети и не записывает их в файл. Передача последнего принятого результата в системный буфер допускается только по явной команде пользователя. Буфер принадлежит ОС; его история, доступ других программ и синхронизация находятся вне управления приложения».

До принятия уточнения базовая SRS 0.1 сохраняет силу, FR-010 не включается в реализацию. Остальные NFR не меняются. Связи: [SDD V1 и V4](../sdd/sdd-template.md), [ADR-0004](../adr/0004-clipboard.md), [план 0.3](../plan/plan.md), [раунд 2](../plan/negotiations.md).
