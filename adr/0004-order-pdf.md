# Серверное формирование PDF заказ-наряда

## Контекст и постановка задачи

Заказчику нужна печатная форма с сохранёнными работами, деталями и итогом.

## Драйверы решения

Предсказуемое оформление, кириллица, одинаковые реквизиты, целостность данных.

## Рассмотренные варианты

Серверный PDF из шаблона, браузерная печать HTML, ручное заполнение.

## Итог решения

Сформировать PDF на сервере из сохранённого снимка заказа. Выбор библиотеки отложить до проверки кириллицы и переноса строк.

## Последствия

Добавляется шаблон документа и проверка оформления. Получение PDF не меняет заказ-наряд.

## Подтверждение

Сверить номер, кириллицу, несколько строк запчастей и суммы в PDF с сохранённым нарядом.

## Связанные требования

FR-008, F10. [Каталог требований](../src/requirements.md).
