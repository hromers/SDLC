# 0004 Копирование результата стандартным API Java

## Контекст и постановка задачи

В учебном раунде 2 предложено переносить результат в другую программу. Реализации в текущей версии нет. Нужно избежать подключения библиотеки и сохранять состояние при ошибке ОС.

Связи: FR-010, проект уточнения NFR-002; [SDD](../sdd/sdd-template.md).

## Драйверы решения

Явная команда пользователя; простой текст с кириллицей; стандартная библиотека; обработка недоступного буфера.

## Рассмотренные варианты

Системный буфер через AWT; Экспорт в текстовый файл; Экспорт в PDF с библиотекой.

## Итог решения

Предложить Toolkit.getDefaultToolkit().getSystemClipboard() и StringSelection; setContents вызывается только по кнопке после успешного расчета.

## Плюсы и минусы вариантов

AWT уже входит в java.desktop. Текстовый файл вводит хранение на диске и диалог пути. PDF требует несоразмерной реализации или зависимости; она не добавляется.

## Последствия

Данные покидают память приложения и могут читаться другими программами; ОС может синхронизировать буфер. Нужны уточнение NFR-002 и явное действие. IllegalStateException, HeadlessException и запрет доступа обрабатываются без изменения модели.

## Подтверждение

После реализации: демонстрация недоступности кнопки до расчета, точности текста, сохранения результата при отказе буфера. Пока подтвержден только контракт официального API; функции в коде нет.
