# Идеальное похудение

Учебный калькулятор тренировочного пульса, вариант 17. Автор: Лапко М. А., группа 450504, БГУИР.

Java Swing, MVC с активной моделью. Возраст и пульс покоя используются в формуле Карвонена с интенсивностями 50% и 70% резерва пульса. Выбор тренажера отображается в результате и не меняет формулу. Программа не является медицинской рекомендацией.

## Запуск

Нужны JDK 21 и графическая среда ОС. Из корня репозитория:

```sh
javac -encoding UTF-8 -d out src/main/java/*.java
java -cp out Main
```

Сторонние библиотеки не используются. Последние принятые параметры хранятся только в памяти до закрытия приложения.
