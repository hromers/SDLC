# Идеальное похудение (вариант 17)

Автор: Лапко М. А., группа 450504
Дисциплина: Жизненный цикл разработки программного обеспечения

Приложение для расчёта пульса при тренировках по формуле Карвонена. Пользователь указывает возраст и пульс в покое, выбирает тренажёр и получает начальную цель на уровне 50% резерва пульса и целевой уровень 70%.

Программа написана на Java с использованием Swing. Взаимодействие построено по MVC с активной моделью.

## Запуск

```bash
cd lab1
javac -d out src/*.java
java -cp out Main
```
