# Станция технического обслуживания автомобилей

Лабораторная работа № 4 по дисциплине «Жизненный цикл разработки программного обеспечения». Проект охватывает учёт клиентов, автомобилей, записей на обслуживание, заказ-нарядов и запчастей.

| Материал | Содержание |
| --- | --- |
| [SRS](srs/srs-template.md) · [требования в src](src/requirements.md) | Функциональные и нефункциональные требования, критерии приёмки |
| [SDD](sdd/sdd-template.md) | Семь представлений системы, диаграммы и трассировка |
| [ADR](adr/README.md#решения-проекта-сто) | PostgreSQL, расписание, состояния, PDF |
| [Матрица и планы](plan/plan.md) | Приоритеты, зависимости, оценки и три версии плана |
| [Переписка](plan/negotiations.md) | Два раунда ролевого обсуждения |
| [SQL-схема](src/main/sql/01_create_schema.sql) | Десять таблиц, ключи и ограничения PostgreSQL |

Исходный материал СТО — схема из лабораторных по базам данных. SRS реконструирована на её основе. История `lab3` и `lab4` относится к отдельному проекту «Идеальное похудение».

В репозитории есть SQL-описание базы. Веб-сервисы, PDF и критерии качества представлены как проект и план реализации. SQL предназначен для развёртывания в пустой схеме.
