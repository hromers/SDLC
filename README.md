## О проекте

Приложение рассчитывает пульс для тренировок по формуле Карвонена. Пользователь вводит возраст и пульс в покое, выбирает тренажёр. Программа показывает начальный пульс для нагрузки 50% и целевой пульс для нагрузки 70% резерва.

Приложение разрабатывается на Java с использованием Swing и архитектуры MVC с активной моделью.

## Структура

Исходный код будущего проекта будет храниться в `src/main/java`. На этом этапе каталог пуст.
